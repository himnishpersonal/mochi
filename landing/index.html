LOCAL AGENT HARNESS

How the agent harness works.

Choose a workflow to suggest a title and folder or find follow-ups. The local model reads the note and transcript, then MOCHI checks the proposal before showing it to you.

  • Review, edit, or dismiss the proposed changes.
  • Approve before MOCHI files a note or adds follow-ups.
  • Changes and an activity record are saved locally.
Uses local Qwen. No automatic external actions.
MCP SHARING

Use your notes in other tools.

MOCHI's optional read-only MCP server gives a connected client access to the notes you choose—without opening your whole library.

  1. Select notes or folders in Settings.
  2. Choose whether to include transcripts and personal notes.
  3. Start the server and configure a client with the local bridge.
Local server tested. Claude Desktop setup is not yet verified end to end; reconnecting after a server restart requires an updated session command.

MCP is off by default. Content retrieved by a connected AI service is sent to that service. The rest of your library remains outside the sharing scope.
